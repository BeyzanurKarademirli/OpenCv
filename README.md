# OpenCV Kamera

Bu proje, OpenCVSharp kullanarak bilgisayarınızın kamerasından canlı görüntü akışını Windows Forms arayüzünde gösterir. Nesne tanıma veya kutu çizme özelliği yoktur; sadece kamera görüntüsü ekranda tam olarak gösterilir.

## Özellikler
- Canlı kamera görüntüsü (tam ekran)
- Başlatmak için `S` tuşuna basın
- Durdurmak için `Q` tuşuna basın
- Kullanıcı dostu arayüz

## Kurulum
1. Projeyi klonlayın:
2. 2. Gerekli NuGet paketlerini yükleyin:
- `OpenCvSharp4`
- `OpenCvSharp4.Windows`
- `OpenCvSharp4.runtime.win`
3. Projeyi Visual Studio ile açın ve çalıştırın.

## Kullanım
- Uygulamayı başlatın.
-`S` tuşuna basarak kamerayı başlatın.
- `Q` tuşunabasarak kamerayı durdurun.

## Gereksinimler
- Windows işletim sistemi
- .NET Framework 4.7.2
- Bilgisayarınızda bir kamera olmalı
